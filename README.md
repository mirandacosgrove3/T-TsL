# T-TsL

A fast, touch-first falling-block puzzle game for phones. Plays as an installable web app: open it in Safari, then Share → Add to Home Screen.

- Modes: Marathon, Sprint 40, Ultra, Master (M1–M30), Zen, Still, Countdown
- Drag & tap or button controls, with adjustable DAS/ARR, lock delay and flick sensitivity
- Works offline once installed
